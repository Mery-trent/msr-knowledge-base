# Requirements: MSR Knowledge Base
Customer: MSR Reaserch Group Lead

## User Stories
| US1 | As a PhD student, I want to switch between four sections using tabs, so I can quickly find the type of information I need. 
| US2 | As a PhD student, I want to see available data sources with thier data type and description
| US3 | As a researcher, I want to see collection methods with pros and cons, so that I can pick the right collection approach. 
| US4 | As a researcher I want to see analysis methods with type and use so that I can choose how to analyze my data. 
| UC5 | As a researcher, I want to compare publication venues by type and MSR relevance, so that I can pick where to publish.
| US6 | As a new student, I want a clean, readable layaout, so that I can focus on content.
| US7 | As a student, I want the page to work on my phone or laptop, so that I can read it anywhere. 

## non-functional
- simple, profissional design, no animation.
